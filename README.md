# Classic Us — Decompiled Sources & Analysis

Decompiled C# sources, IL2CPP reference assemblies, raw metadata dumps, and a
security audit for **Classic Us** (an Among Us–style game, Linux IL2CPP builds).

Covers two official releases:

| Build | C# decompile | IL2CPP interop DLLs | Raw IL2CPP dumps |
|---|---|---|---|
| **2026.9.2** | `decompiled_src/` | `cpp2il_dlls/` | `il2cpp_dump/` |
| **2026.9.5** (current) | `decompiled_src_95/` | `cpp2il_dlls_95/` | `il2cpp_dump_95/` |

## Content

- **`decompiled_src*/`** — full C# project (`Assembly-CSharp.csproj`) generated by
  [ilspycmd](https://github.com/icsharpcode/ILSpy) from the interop assemblies.
  Class definitions, fields, properties and method signatures for every managed
  type (game + Unity + third-party). Method *bodies* are absent by design:
  IL2CPP compiles to native code, so only signatures survive decompilation.
- **`cpp2il_dlls*/`** — reference assemblies produced by
  [Cpp2IL](https://github.com/SamboyCoding/Cpp2IL) (88–89 DLLs). Suitable as
  reference inputs for Il2CppInterop / BepInEx tooling.
- **`il2cpp_dump*/`** — raw metadata dumps from Il2CppDumper:
  `dump.cs` (types/methods), `il2cpp.h` + `script.json` (symbol → address
  mappings for disassemblers like Ghidra/IDA), `stringliteral.json`.
- **`classicus_full_audit.md`** — full inbound network-surface audit: every
  RPC / server-message dispatcher decoded and classified (13 dispatchers).
- **`classicus_exploits.txt`** — vulnerability findings with RVAs, wire layouts,
  impact and fix status. *Research documentation — for the maintainers / your
  own testing only.*
- **`tools/`** — analysis tooling used to produce the audit:
  - `sweep_tables.py` — jump-table / if-chain dispatcher decoder
  - `annotate95.py` — RVA → symbol annotation for the 2026.9.5 binary
  - `ui_driver.py` — headless UI experiments
  - `cpp2il` — self-contained Cpp2IL binary (metadata v31 capable)
- **`harness_rpc13/`** — research test harness used to verify the RPC findings
  at runtime (source only — no compiled plugin, no BepInEx runtime bundled)

## Environment / versions

- Unity **2022.3.62f3**, IL2CPP x86_64, metadata **v31**
- Cpp2IL `2022.1.0-pre-release.21` (self-contained Linux build)
- ilspycmd (latest)
- Il2CppDumper v6 format (`dump.cs`/`il2cpp.h`/`script.json`/`stringliteral.json`)

## Reproducing the decompile (2026.9.5)

```bash
# 1. Cpp2IL → interop DLLs (88 DLLs into cpp2il_out/)
./tools/cpp2il \
  --force-binary-path     "GameAssembly.so" \
  --force-metadata-path   "classicus2026.9.5linux_Data/il2cpp_data/Metadata/global-metadata.dat" \
  --force-unity-version   2022.3.62f3 \
  --output-as dll_default --output-to cpp2il_out

# 2. ilspycmd → C# project (run from a sibling dir so HintPaths resolve)
mkdir decompiled_src_95 && cd decompiled_src_95
ilspycmd -p -o . ../cpp2il_dlls_95/Assembly-CSharp.dll
```
